# LocalGPT Overview

LocalGPT is an offline, private, local generative AI assistant powered by Qwen2.5-1.5B-Instruct.
It runs completely on your personal laptop without connecting to OpenAI, Gemini, Claude, or any external LLM APIs.

## Key Features
1. Multi-turn Conversational AI with custom personas (Python Tutor, Concise Analyst, Creative Writer).
2. Local Document Retrieval-Augmented Generation (RAG) using semantic embeddings and vector search.
3. Neural Network X-Ray Visualizer for inspecting Tokenization, Embeddings, Attention, Hidden States, and Logits.
4. Privacy-first architecture: All documents, embeddings, and chat histories remain strictly on your local disk.
